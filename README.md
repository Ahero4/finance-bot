# Finance Bot

Telegram-бот для учёта расходов. Работает только в личном чате. Суммы — целые положительные числа до 9.223.372.036.854.775.807, описание — непустой текст до 255 символов. Вводите суммы без разделителей (25000); бот показывает 25.000 ₽ или 25.000 $.

Python 3.10+; установка и запуск из PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:BOT_TOKEN = 'ваш токен от BotFather'
.\.venv\Scripts\python.exe bot.py
```

BOT_TOKEN обязателен. Значения из `.env` автоматически не загружаются. Токен храните вне исходников. Если токен раньше публиковался, отзовите его у BotFather.

Для подготовленного локального окружения `.venv-audit` можно сохранить `BOT_TOKEN=...` в исключённом из Git файле `.env` и выполнить `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Этот скрипт читает токен без вывода на экран и передаёт его боту через окружение.

По умолчанию SQLite-файл `db.sqlite` расположен в каталоге проекта независимо от текущей рабочей директории. Необязательная переменная `DATABASE_URL` позволяет указать другую БД:

```powershell
$env:DATABASE_URL = 'sqlite+aiosqlite:///C:/absolute/path/to/finance.sqlite'
```

Существующая таблица расходов совместима; схема и старые записи не меняются. При запуске добавляется отдельная таблица персональных настроек. `/start` сбрасывает текущий диалог. Отчёты за месяц разбиваются на сообщения при превышении лимита Telegram.

Проверки без Telegram и рабочей БД:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют временные SQLite-файлы и имитацию сетевых ответов. Файл `reqiurements.txt` сохранён как ссылка на `requirements.txt` для совместимости старых команд установки.

## Отчёты и настройки

- ⚙️ `/settings` — валюта отображения: RUB ₽ (по умолчанию) или USD $. Выбор сохраняется персонально. Все расходы отображаются в выбранной валюте; переключение меняет только знак, без пересчёта и конвертации.
- 📋 «Показать траты» сразу открывает текущий календарный месяц. «📅 Другой период» — прежний выбор года и месяца.
- 📊 «График расходов» строит PNG в Python: неделя — последние 7 дней включая сегодня, месяц — текущий календарный месяц, год — текущий календарный год. Столбцы идут по дням или месяцам; дни без трат показаны нулями. При отсутствии записей выводится сообщение.
- 🗓 «Свой период» доступен в отчёте и меню графика. Введите `11.09.2026 - 13.10.2026`; обе даты включены. Даты должны быть реальными и идти по порядку. Для графика до 62 дней отображаются дни, до 24 календарных месяцев — месяцы, далее — годы или группы лет (не более 24 столбцов). Фактическая агрегация указана в подписи.
- `/start`, `/settings` и отмена сбрасывают текущий ввод. Просмотр строится по локальному времени процесса бота, как и дата сохранения расходов.

Финансовые данные и настройки разделены по пользователям. Графики создаются в памяти и не сохраняются на диск.
